# Bài tập: Phối màu cho Newsletter

Dự án gồm hai phiên bản newsletter responsive, dùng Bootstrap 5 và hai bảng màu khác nhau.

## Phiên bản

- Version 1 — Ocean Edition: xanh dương #155EEF, xanh navy #163B65, xanh ngọc #35C6B4, nền xanh nhạt #F2F7FC.
- Version 2 — Warm Edition: đỏ đất #B9472F, nâu trầm #542F2A, vàng ấm #F2B84B, nền kem #FFF7EF.

## Cách xem

Mở từng file HTML bằng trình duyệt. Bootstrap và Google Fonts được tải qua CDN nên cần Internet để hiển thị đầy đủ.

## Nguyên tắc thiết kế

- Giữ cấu trúc newsletter nhất quán để dễ so sánh tác động của màu sắc.
- Dùng màu chủ đạo cho CTA và tiêu đề, màu phụ cho vùng nền đậm, màu nhấn cho chi tiết quan trọng.
- Có trạng thái hover cho nút và thẻ nội dung.
- Bố cục tự điều chỉnh theo màn hình nhỏ bằng Bootstrap và media query.
- Nội dung chữ và nền được chọn để duy trì khả năng đọc tốt.
